📊 Retail Sales Dashboard – Power BI

📌 Project Overview
This project presents an interactive Retail Sales Dashboard created using **Microsoft Power BI** to analyze business performance and sales trends. It provides insights into revenue, profit, orders, customer segments, and product performance through visualizations and KPI cards.

🎯 Key Features
- **KPI Cards:** Total Sales, Total Profit, Profit Margin, Total Orders and Average Order Value.
- **Monthly Sales Analysis:** Compares sales trends across different years.
- **Category Analysis:** Visualizes sales and profit by product category.
- **Sub-Category Analysis:** Highlights profit margins across sub-categories.
- **Segment Analysis:** Displays sales distribution among customer segments.
- **Top 5 Products:** Identifies the highest-performing products based on sales.

🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

 📈 Dashboard Insights
The dashboard helps users:
- Monitor overall sales and profitability.
- Identify monthly sales trends.
- Compare category-wise performance.
- Understand customer segment contributions.
- Identify top-performing products.
